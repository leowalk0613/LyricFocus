## 新增（两渠道）
- **按歌曲 ID 直取歌词**：网易云 / QQ 音乐 / 小米音乐优先用平台 ID 拉歌词，失败再回退标题+歌手搜索
- **多行 · 仅当前行显示翻译**：开启后仅当前句下方显示翻译，后续行只显示原文
- **多行行距可调**：设置中调节原文行间距（0–100dp，默认 50）；翻译紧跟间距仍为 2dp

## 修复 / 优化（本包替换）
- **网络源切歌同步**：切歌立刻取消旧拉取、清空状态并推送 `loading`，避免外部渲染残留上一首
- **网易云 focus ID 滞后**：焦点通知 songId 与当前歌名不匹配时丢弃过期 ID，改搜歌名；通知追上后按新 ID 重拉
- **外部歌词协议**：推送增加单调 `seq` 与发送端 floor，接收端应丢弃过期包；去重键不再含 `isCur`（避免每换行狂发全量 FD）
- **会话健康检查**：按曲名/艺人/`MEDIA_ID` 与 playback state 刷新，减少对象引用误判
- **歌词源说明**：标题与描述对齐真实拉词逻辑（自动按播放器选源等）
- 修复更新检测误报（忽略渠道后缀再比较版本；下载优先本渠道 APK）
