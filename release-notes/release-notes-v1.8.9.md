# V1.8.9

## 新增
- LRCLib 海外开源歌词源（独立源，不参与 Auto 自动切换）
- 桌面图标隐藏开关
- 主页"隐藏桌面图标"快捷入口

## 修复
- 切歌后上首歌词残留焦点通知
- 多艺人歌曲匹配（分号分隔的艺人名）
- 日语 / 多艺人搜索精度
- AI 翻译纯文本输出容错（不再强制要求 LRC 格式）
- 前台通知精简为不可见（`IMPORTANCE_MIN` + 透明图标）
- Lyricon 词幕翻译同步（250ms 窗口合并）

## 优化
- QQ 音乐源改为纯原文（不含翻译），翻译走自动 / 网易源
- Auto 模式：QQ 确认歌曲 → 网易拿歌词翻译（有翻译才替换）
- 取色透明度描述追加「针对焦点通知背景」
- 日志默认只显示最新（不再扫 `log.old`）
- 多行歌词卡片置顶到锁屏样式第一位
- 众多稳定性与性能优化
