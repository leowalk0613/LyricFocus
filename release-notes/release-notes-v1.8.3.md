## v1.8.3

### 全新歌词源

- **SuperLyricApi**：实时推送单行歌词，通过 AIDL 接收。仅支持单行模式，不支持翻译
- **LyricInfo**：通过 Xposed 注入 `MediaMetadata.extras.lyricInfo` 读取 LRC，零外部依赖，支持完整歌词+翻译
- **词幕 Lyricon**：`LyriconFactory.createSubscriber` 接收完整歌词+翻译，需安装 LyricProvider Xposed 模块

### 歌词源管理升级

- 主页歌词获取源改为二级界面（独立 Activity），类似白名单管理
- 二级界面内嵌歌曲调试信息卡片：当前播放/匹配歌词/来源/翻译/专辑/AI 状态
- 每个源可展开查看注意事项（本地 LRC、AI 配置内联、SuperLyric/LyricInfo/Lyricon 提醒）

### 服务状态卡片

- 服务状态独立为卡片，置于副标题下方
- 显示当前 AOD 模式、播放歌曲、歌词来源
- 运行中：卡片背景取 `colorPrimary`，文字白字加粗；未运行：保持默认

### 多行歌词模式重构

- 当前行可完全展开（`maxLines=4`），字号保持原大 + 强调色
- 其他原文 0.65x + 专辑取色，翻译 0.65x+2sp 淡化
- 当前行与翻译组成视觉单元，内部紧凑，外部拉大间距
- 多行通知只在锁屏/AOD 展开，通知栏自动收为双行
- 固定多行通知大小（`minHeight`），不会因剩余歌词不够而缩小
- 预览完全对齐实机多行渲染逻辑（颜色、字号、当前行位置）

### 性能优化

- 移除切歌时的「加载歌词中」占位通知（每切歌少一轮通知构建+广播）
- 长前奏歌词不跳首句：未命中行时显示第一行歌词而非歌名

### 歌词匹配优化

- **专辑优先**：网易云/QQ 搜索加入专辑名匹配加分（精确+10, 模糊+5）
- 已知歌曲 ID 直绑：「それでも僕らは歌うことをやめない」(Leo/need)、「Reach Out To The Truth」(平田志穂子)
- 本地 LRC 文件匹配改为先精确比文件名，再走规则打分

### 构建系统升级

- Gradle 8.11.1 / AGP 8.9.2 / Kotlin 2.3.20 / compileSdk 36 / Java 21

### 样式预览重构

- 预览卡片改为 MaterialCardView，匹配整体 UI 设计语言
- 多行预览取色/字号/当前行逻辑完全对齐实机

### 版本号

- `1.8.3` (versionCode 23)
