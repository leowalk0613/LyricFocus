## v1.8.8

### 新增
- **锁屏文字颜色**：推荐色预设 + 自定义取色（RGBA + 色值输入），与白色/黑色并列为文字颜色选项
- **焦点通知背景自定义**：新增「自定义」背景选项，支持 RGBA 取色器
- **取色透明度**：通用设置中新增取色透明度滑块（10%-100%），仅影响焦点通知背景
- **万象息屏 AOD 文字颜色**：新增自定义取色器（RGBA + 色值输入）

### 优化
- **多行歌词重写**：
  - 当前行始终在最上方，后续按序线性填充，空行隐藏
  - 有翻译时不再严格配对，有空位就填
  - 当前行原文加粗可换行显示完整，翻译单行省略号
  - 行间距大幅缩小
  - 通知宽度/高度固定，不随内容变化
- **取色逻辑**：关闭色彩模式取色偏向可读性（高对比度），开启偏向保留色彩；杜绝白底白字/黑底黑字
- **AI 缓存**：关缓存不再删除已有数据；并发请求去重防重复调用 API
- **背景选项**：默认/纯黑 一行，纯白/自定义 一行，互斥选择
- **万象息屏开启时**：多行模式自动禁用
- **调色器 UI**：统一 Material 风格，大色块预览 + RGBA 滑条 + 色值输入框

### 修复
- 锁屏切歌后 AOD 通知空白不刷新（切歌时 AOD 走 cancel+notify 重建）
- `lock_screen_color_palette` GridLayout 类型不匹配导致样式页闪退
- 多行歌词死循环卡 SystemUI（加迭代上限保护）
- 取色透明度滑块实时触发大量广播卡通知中心（改为松手才发）
- Fragment 内存泄漏修复（`onPreviewStateChanged`、`cachedFocusRow`、`previewHeightAnimator`）
- 热路径 Regex 预编译为常量

### 移除
- 焦点通知背景专辑取色功能（实现有缺陷，后期重写）
