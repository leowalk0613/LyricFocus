## v1.6.1

### 新功能

- **AI 连通性检测**：AI 翻译配置页可对当前填写的 Base URL / API Key / 模型发起轻量连通测试，无需先保存
- **翻译所有歌词**：可选开关（默认关闭）；开启后用 AI 译文覆盖在线源已有翻译，关闭时仅在无译文时调用 AI
- **自启动权限状态**：权限设置新增自启动项，尽量检测 MIUI / HyperOS 状态并可跳转系统页

### 优化

- **权限设置重排**：分为「必要权限」与「其他权限」；每项附用途说明；授权状态改为标题前绿 / 红图标
- **AI 配置说明**：文案改为适用各类兼容 OpenAI Chat Completions 的 API（OpenAI、DeepSeek、通义、自建中转等）
- **焦点通知渠道文案**：系统界面渠道更名为「LyricFocus 焦点歌词」，描述对齐锁屏 / 息屏用途
- **应用图标**：全新对话气泡 + 音符图标；自适应图标支持壁纸 Monet 取色与主题图标（monochrome）
- **焦点通知背景**挪至「通用（全部样式）」，与 Monet / 文字取色同一区域管理
- **版本与更新弹窗**：更新日志可滑动查看完整内容；工具栏改用菜单项，避免首次点开被误关

### 说明

- 息屏通知切换偶发动画抽搐暂未继续跟进（不影响歌词显示）
- 超级岛显示仍固定关闭（界面无可选项）

### 版本号

- `1.6.1`（versionCode 17）

## 安装说明

- 下载 `LyricFocus.v1.6.1.apk` 安装
- 若曾安装 Debug 版，请先卸载再安装
- 需要 LSPosed，作用域：`com.android.systemui`、`com.miui.aod`
- 安装后请在 LSPosed 中重新勾选上述作用域并**重启 SystemUI**
