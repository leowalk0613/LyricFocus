# V1.9.3(OS3) 更新

> ## ⚠️ 重要提醒
> **本包为 HyperOS 3.x 专用（versionName `1.9.3(OS3)`）。**
> **HyperOS 4 用户请使用同版本 OS4 专用包，请勿安装本版！**
> **请勿交叉安装渠道包：OS3 ↔ OS4 焦点 API 不同，错装会导致焦点通知异常。**

## 新增
- 按播放器歌曲 ID 直取歌词（网易 / QQ / 小米音乐），失败再回退标题搜索
- 多行模式：「仅当前行显示翻译」（当前原文下跟翻译，其余只显示原文）
- 多行歌词行距可调（0–100dp，默认 50；翻译紧跟仍为 2dp）

## 修复 / 优化
- **网络源切歌**：取消旧请求、立刻清空并推送 `loading`，避免外部渲染残留上一首歌词
- **网易云 focus 通知滞后**：focus 歌名与当前曲不符时忽略过期 songId，改搜歌名；focus 追上后自动按新 ID 重拉
- 外部歌词协议：`seq` 单调序号 + 发送端 floor，防止迟到的旧 `putlyricfd` 盖住清空
- 健康检查：按 title/artist/`MEDIA_ID` 与 playback state 判断，减少误刷
- 歌词源文案与真实拉词逻辑对齐（自动按播放器选源等）
- 关于页与更新检测：忽略渠道后缀比较版本；下载优先本渠道 APK
