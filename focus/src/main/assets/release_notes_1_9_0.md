# V1.9.0 更新

## 新增
- aodchange 外部渲染模式：歌词数据通过 ContentProvider 推送到 aodchange 模块渲染，开启后本模块不再注入 hook，避免模块冲突
- 焦点通知歌词总开关：关闭后不注入任何 hook
- 更新对话框改版：GitHub / Gitee / 123云盘 三渠道下载
- 焦点通知防闪烁（FocusedNotifPrompt 动画压制）

## 修复
- Lyricon 词幕同时间戳歌词合并逻辑（仅合并时间戳完全相同的行，避免快节奏歌曲整句被吞）
- 切歌后 AOD 残留上一首歌词
- 万象息屏色彩模式黑底双色对比度

## 优化
- AOD 歌词去重与边沿检测，减少重复动画
- 歌词刷新间隔 5s → 1s，切歌响应更快
- 重启 SystemUI 时同时重启 AOD 进程，hook 开关即时生效
- 冗余代码清理
