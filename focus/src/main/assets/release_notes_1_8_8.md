## v1.8.8

### 新增
- **Monet 仅背景取色**：Monet 开关下新增「仅背景取色」选项，背景走专辑色，文字可手动自定义
- **锁屏文字颜色推荐色 + 自定义**：RGBA 滑条 + 色值输入
- **焦点通知背景自定义颜色**：支持 RGBA 取色器
- **万象息屏 AOD 自定义文字颜色**
- **取色透明度**：通用设置中滑块 10%-100%，仅影响通知背景

### 多行歌词重写
- 当前行始终置顶，后续线性填充，空行隐藏
- 当前行原文加粗可换行，翻译单行省略号
- 通知宽度/高度固定，不随内容变化
- 行间距大幅缩小

### 优化
- 取色逻辑：关色彩模式偏向可读性，开色彩模式保留彩度；杜绝白底白字/黑底黑字
- AI 缓存：关缓存不删数据；并发请求去重
- 调色器 UI 统一：Material 风格大色块 + RGBA 滑条 + 色值输入
- 预览窗口动画防抖

### 修复
- AOD 切歌空白不刷新
- 样式页 GridLayout 闪退
- 多行尾句死循环卡 SystemUI
- WelcomeActivity 权限色值崩溃（issue #24）
- 取色透明度滑块实时广播卡通知中心
- Fragment 内存泄漏（回调/View/动画）
