### 新功能

- **歌词焦点通知永久置顶**：焦点通知数据层与视图层将歌词卡片置顶，覆盖 HyperIsland、倒计时焦点通知等；`pinAboveMedia` 默认始终开启
- **本地 LRC 歌词源**：应用内选择文件夹（SAF）读取 `.lrc`；智能文件名匹配；三语 LRC（原文 / 翻译 / 读音）合并显示
- **AI 翻译歌词源**：兼容 OpenAI Chat Completions API，为无译文歌词生成翻译

### 修复

- **QQ 音乐歌词源失效**：搜索迁移至 `musicu.fcg`，歌词改用 `i.y.qq.com` 明文接口
- **网易云极短标题误匹配**：修复 `p.h.` 等歌曲误匹配为同艺人其他曲目
- **歌词通知被压在下方**：修复锁屏焦点卡片无法通过通知栈重排置顶的问题

### 优化

- 焦点置顶 hook 稳定性（防重入、缩小 hook 范围）
- 三语 LRC 解析（同时间戳合并、续行、行内 `|` / `/` 分隔）
- 应用内可查看本版本更新说明
- 万象息屏标题图标文案修正
- 歌词搜索关键词策略增强
