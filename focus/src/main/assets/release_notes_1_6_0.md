### 新功能

- **歌词焦点通知永久置顶**：焦点通知数据层与视图层将歌词卡片置顶，覆盖 HyperIsland、倒计时焦点通知等
- **本地 LRC 歌词源**：应用内选择文件夹读取 `.lrc`；支持三语文件（原文 / 翻译 / 读音）与智能文件名匹配
- **AI 翻译歌词源**：兼容 OpenAI Chat Completions API，为无译文歌词生成翻译

### 修复

- **QQ 音乐歌词源失效**：迁移至 `musicu.fcg` 搜索与 `i.y.qq.com` 歌词接口
- **网易云极短标题误匹配**：修复 `p.h.` 等歌曲匹配错误
- **歌词通知排序无效**：修复锁屏焦点卡片无法置顶的问题

### 优化

- 焦点置顶 hook 稳定性提升
- 三语 LRC 解析（同时间戳合并、续行、行内分隔）
- 应用内可查看本版本更新说明
- 万象息屏标题图标文案修正
