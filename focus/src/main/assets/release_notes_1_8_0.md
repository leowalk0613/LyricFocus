## v1.8.0

### ⚠️ LSPosed 框架要求
完整迁移至 Modern Xposed API (LSP 2.0 / API 102)，必须更新 LSPosed 至 2.0 版本！旧版 LSPosed (API 82) 不再兼容。

### 新功能
- 万象息屏仅显示歌词：播放时 AOD 自动隐藏其他通知
- AOD 过渡动画保护：锁屏↔AOD 切换不丢歌词视图
- Monet 图标适配：应用图标背景随壁纸动态取色

### 优化
- 锁屏/AOD 通知刷新统一为 notify-only（无动画）
- 窗口高度调整：底部按钮无需滑到最底
- 歌词置顶增强：播放时歌词通知确保第一位
